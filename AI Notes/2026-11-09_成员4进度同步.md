## 当前PC跳跃规则

- 代码默认力度0.30g，设置滑条范围0.10–0.80g；本机玩家配置不进入Git，新同学启动采用默认值。
- 向上分量连续40ms达到玩家门槛才触发；水平分量和翻腕角速度不再直接否决。
- 明显下压（小于-0.25g）只抑制随后120ms，持续下压会续期；取消较轻下沉的长时间锁定。
- 成功后700ms冷却，不要求精确静止；力度释放到门槛一半以下后允许下一次动作，持续高加速度不自动连跳。
- 同设备UI切换保留重力/陀螺参考；旧力度释放且经过80ms可恢复。断连、异常时间间隔和重新校准仍重新建立参考。
- 弱下压刹停或侧甩混入向上分量可能误跳，是用户已明确接受的易用性取舍。

## 与1号对接的协议

USB CDC按115200、8N1、换行分帧接收；约50Hz。v2示例结构：

```text
ROLL:0.7,PITCH:0.5,JUMP:0,V:2,T:123456,AX:0,AY:0,AZ:16384,GX:0,GY:0,GZ:0
```

Roll/Pitch为度；T为设备毫秒tick；六轴为原始有符号整数，加速度16384LSB/g、陀螺131LSB/(°/s)。向上模式由PC六轴检测器产生事件，固件原JUMP字段仅保留诊断，不直接当成PC跳跃指令。

硬件I²C仍为PB8/SCL、PB9/SDA。供电和烧录接线以`motion-controller/PROJECT_GUIDE.md`为准。v2产物及升级说明见`motion-controller/releases/README_v2.md`。

## 运行与验证

从仓库根目录，用本机Python创建虚拟环境后运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r MotionGolf_Stage1_v4/requirements.txt
.\.venv\Scripts\python.exe MotionGolf_Stage1_v4/main.py
```

连接兼容v2设备，保持自然握持，F4校准后点击Start / Resume。没有硬件时可切Keyboard备用。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s MotionGolf_Stage1_v4/tests -v
```

`AI Notes/diagnostics/launch_gesture_diagnostic.py`可在关闭其他串口客户端后启动带记录的游戏。`temporary_i2c_recovery.py`默认只读；其`--apply`会临时写外围寄存器，只应在明确的现场调试授权和正确接线下使用。
