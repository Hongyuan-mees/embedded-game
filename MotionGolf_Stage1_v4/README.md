# Motion Golf：STM32 主控版本

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r MotionGolf_Stage1_v4/requirements.txt
.\.venv\Scripts\python.exe MotionGolf_Stage1_v4/main.py
```

## 连接和开始

启动默认STM32模式，并打开设置面板，游戏计时暂停。只有一个匹配的USB CDC设备时会尝试连接；否则用左右按钮选择当前COM口，再点Connect / Retry。先退出其他占用串口的终端。

端稳手柄，点击Calibrate或按F4，等待Calibration complete，再点Start / Resume。校准按当前自然握持姿态进行，重新连接设备后需要重新校准。

Close / F5始终可以关闭设置，即使没有数据也不会卡住界面。Start / Resume仅在选定输入可用时启用；连接失效时游戏保持暂停，也可以主动选Keyboard备用后继续。正常游戏中断后，按Connect / Retry重连，再按F4校准，最后点Start / Resume恢复。

`MPU6050_ERROR,HW_SCAN_COUNT:0` 表示固件扫描不到传感器，USB串口存在并不等于传感器正常。此时先恢复供电/I2C连接；反复Retry不能修复传感器通信。首次等待有效数据窗口为3秒，正常控制数据中断仍以250ms超时归零。已收到的传感器错误会保留到有效数据恢复，不被重试后的通用超时提示掩盖。

当前实物朝向已验证：右侧压低使Roll增大，前端压低使Pitch增大；游戏因此保持Roll同号、反转Pitch，不交换轴。改变模块安装或握持朝向后应重新核对。

## 向上跳跃与力度设置

方向跳跃需要v2固件，见 `../motion-controller/releases/README_v2.md`。旧固件仍可用于校准和倾斜移动，游戏会显示Legacy提示并禁用硬件跳跃，不把旧的任意方向JUMP信号当成向上手势。

F5打开设置面板，调整Upward jump threshold滑条：0.10至0.80g，默认0.30g。数值越高，需要越明确的向上提拉。Light、Standard、Firm分别为0.18、0.30、0.45g，均为待实物调优的初始值。

这里的g是重力补偿后的向上加速度，不是原固件包含重力的1.18g模长。它不改变球的跳跃高度或倾斜控制灵敏度。

面板显示实时向上力度、阈值标线和试跳次数；试跳时游戏保持暂停。修改后保存到游戏目录的 `user_settings.json`，该文件不进入Git。设置损坏时恢复默认，写入失败会在面板中提示。

当前采用“易触发优先”的判定，按玩家反馈接受少量误跳。初始力度保持0.30g，向上分量连续40ms超过玩家设定值即可触发；首次连接和F4校准仍需要短暂握稳以测量重力参考。

横向分量及翻腕角速度不再直接否决上提。纯水平移动通常没有足够的向上分量；侧甩伴随上抬、较慢下压后的刹停可能产生误跳，这是优先减少漏判所接受的取舍。

明显下压（竖直小于-0.25g）只短暂抑制后续120ms，持续下压会续期；轻微预备下沉不触发长时间锁定。候选没有达到要求就返回等待，不设置惩罚冷却。

成功跳跃后仅有固定700ms冷却，不再要求连续精确静止。期间只需向上力度曾回落到设定值的一半以下，就能在冷却结束后识别下一次动作；持续高加速度不会自动重复跳跃。

Start / Resume、暂停、设置及关卡切换保留已测得的重力方向、静止加速度和陀螺零偏，丢弃未完成动作；旧的上提力度释放且经过80ms后即可恢复，无需保持某个精确姿态。新连接、重新校准、协议变化和数据间断仍重新建立参考。

需要诊断动作误触时，先退出游戏，再运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 MotionGolf_Stage1_v4/record_gestures.py
```

按终端提示依次测试上提、下压刹停和横向移动：每次按Enter后保持3秒，看到GO再做一次动作。原始六轴数据、动作标签、检测状态和事件保存在仓库tmp中的JSONL轨迹文件，便于重放分析；传感器报错或缺数据会停止采集，不能当成动作未触发。

## 操作

| 操作 | 功能 |
|---|---|
| F3 | STM32 / Keyboard模式切换 |
| F4 | 请求中立姿态校准 |
| F5 | 打开/关闭控制器设置 |
| F1或P | 暂停/继续 |
| F2或R | 重开当前关卡 |
| [ / ] | 前后关卡 |
| Esc | 退出 |

Keyboard为主动选择的备用模式，WASD/方向键移动、Space跳跃；STM32模式下这些键不控制小球。两个模式共用落地、暂停和通关起跳条件。窗口失焦或主控连接失效时自动暂停，恢复后手动继续。


测试使用模拟六轴轨迹、软件串口回环和SDL无窗口游戏主循环。不能替代新固件烧录后的真实上提、下压、横甩及USB拔插验收。
