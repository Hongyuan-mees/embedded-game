# Motion Golf - Stage 2

新增：
- 正式主菜单
- Start Game / Level Select / Settings
- Easy / Normal / Hard 三档难度
- 5 个关卡
- 墙、低墙、沙坑、水池、球洞
- Jump 越过低墙
- 通关星级评分
- Next Level / Retry / Main Menu
- Game Complete 界面
- 正式 HUD 和简单倾斜动画
- 保留 Stage 1 v4 已验证稳定的键盘控制

运行：

```powershell
python main.py
```

控制：
- WASD / 方向键：模拟倾斜
- Space：Jump
- P / F1：Pause / Resume
- R / F2：Restart
- Esc：返回菜单 / 退出
